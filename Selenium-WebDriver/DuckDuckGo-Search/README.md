# DuckDuckGo Search Automation

## Project Overview
Automated DuckDuckGo search using Selenium WebDriver and Java.

## Technologies Used
- Java
- Selenium WebDriver
- Eclipse IDE
- Chrome Browser

## Concepts Practiced
- Browser Launch
- Browser Navigation
- By.name Locator
- sendKeys()
- Keys.ENTER
- Page Title Verification

## Test Scenario
1. Launch Chrome.
2. Open DuckDuckGo.
3. Locate search box.
4. Enter Selenium WebDriver.
5. Press Enter.
6. Verify page title.
